# Estudos-Python
## Sistema de Cadastro e Gerenciamento de atendimentos

Projeto desenvolvido em Python com a finalidade de praticar a lógica de programação, manipulação de dados, funções, validações e persistencia das informações em arquivos JSON.
O sistema permite que você cadastre pessoas, organize atendimentos por nível de urgência, gere tickets para esses atendimentos, edite e remova cadastros, além dele registrar o histórico de atendimentos com data e hora.

## Funcionalidades

- Cadastro de pessoas;
- Geração automática de tickets;
- Registro de data e hora de abertura;
- Registro de data e hora de atendimento;
- Classificação de atendimento por nível de urgência;
- Fila de atendimento;
- edição de informações;
- Remoção de cadastros;
- Atendimento do próximo ticket;
- Histórico de atendimentos;
- Persistência de dados utilizando o JSON;
- Validação de entradas do usuário.

  ## Como executar o projeto

1 - Clone este repositório:
 ```
  git clone https://github.com/nunesluisa/Estudos-Python.git
```
2 - Acesse a pasta do projeto
  ``` 
cd Estudos-Python
```
3 - Execute o programa
```
  python sistema-cadastro/main.py
```
É necessário ter o python instalado
